# Minecraft 存档打包与导入工具

这是一个简单易用的带图形界面的 Minecraft 存档辅助工具。

## 核心功能

- **扫描与打包**：自动扫描 `.minecraft` 目录下的所有存档（支持原版及多版本隔离目录），并将指定存档打包为 ZIP。
- **一键导入**：将之前打包的存档一键解压并导入到指定的 `.minecraft` 版本目录下。
- **版本数据迁移**：能够自动从旧版本的文件夹中迁移 `mods`、`config`、`saves`、`resourcepacks`、`shaderpacks` 等数据到新版本文件夹中，省去手动复制粘贴的烦恼，并且有进度条显示迁移进度！

## 运行方式

如果你只想使用工具，请直接在 Releases 中下载 `mc_archiver.exe` 双击运行即可。

如果你想从源码运行，请确保已安装 Python 3 环境，并安装 `tkinter` 依赖。

## 界面预览

本工具采用轻量级 Tkinter 开发，拥有如下几个主要选项卡：
1. **打包导出**
2. **一键导入**
3. **版本数据迁移**
